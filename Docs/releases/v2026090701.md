# WinForge v2026090701

[French release notes](https://github.com/VBlackJack/WinForge/releases/download/v2026090701/v2026090701.fr.md)

This release fixes the five actionable groups identified during the CodeQL review.

## Fixed

- The profile save dialog is now displayed and has separate Save and Cancel outcomes. Escape and backdrop dismissal cancel without writing. Invalid names cannot escape the profile directory. Creating a profile cannot replace an existing file without selecting overwrite.
- Profile updates preserve unedited configuration and version fields, including profiles copied from the installation directory into user storage.
- Corrupt deployment history remains intact. Writes use an atomic replacement, and failed reads or clearing operations are reported.
- Failed checkpoint writes and deletions propagate to callers. A batch cannot start without creating its checkpoint. Parallel operations finish their active work before reporting checkpoint errors. The original recovery checkpoint remains available until the resumed operation succeeds.
- Cancelling a silent PowerShell query cancels its redirected stream reads and stops the process without waiting for its normal exit.
- Test services and failed UI test launches release their resources reliably.
- UI smoke tests select their starting page explicitly, follow the existing unavailable-action visibility contract and cover profile-dialog cancellation.

## Hardening

Repository and user-data path factories reject paths outside their root. PowerShell executable discovery uses an instance-owned, thread-safe lazy cache.

The review retains justified defensive handlers, style suggestions and confirmed false positives. Generated-source diagnostics are not product defects; no security query was disabled to hide them.

## Upgrade

Extract the complete archive into a new directory. Existing user profiles and settings remain in their normal user-data directory. If history is corrupt, retain a copy for recovery before explicitly clearing it in Settings. Storage failures must be resolved before retrying a resumable batch.
