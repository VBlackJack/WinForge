# WinForge v2026090702

[English release notes](https://github.com/VBlackJack/WinForge/releases/tag/v2026090702)

Cette version corrige les cinq groupes de défauts retenus après le triage CodeQL.

## Corrections

- Le dialogue de sauvegarde des profils est affiché et distingue Enregistrer et Annuler. Échap et un clic sur le fond annulent sans écriture. Les noms invalides ne permettent plus de sortir du dossier des profils. Un nouveau profil ne remplace pas un fichier existant sans choisir le remplacement.
- Les mises à jour préservent la configuration et la version non modifiées, y compris lors de la copie d'un profil du dossier d'installation vers le stockage utilisateur.
- Le mode remplacement ne modifie que la sélection d'applications. La description et l'héritage masqués restent intacts ; les applications héritées ne sont pas dupliquées en entrées directes.
- Un historique de déploiement corrompu reste intact. Les écritures sont atomiques et les erreurs de lecture ou de suppression sont signalées.
- Les erreurs d'écriture et de suppression des points de reprise remontent aux appelants. Un lot ne démarre pas sans créer son point de reprise. Les opérations parallèles terminent leur travail actif avant de signaler les erreurs de sauvegarde. Le point de reprise original reste disponible jusqu'au succès de l'opération reprise.
- L'annulation d'une requête PowerShell silencieuse interrompt les lectures et arrête le processus sans attendre sa fin normale.
- Les services de test et les lancements de tests graphiques échoués libèrent leurs ressources.
- Les tests graphiques sélectionnent explicitement leur page initiale, respectent le contrat existant de masquage des actions indisponibles et vérifient l'annulation du dialogue de profil.

## Renforcement

Les fabriques de chemins rejettent les destinations hors de leur racine. La recherche de PowerShell utilise un cache propre à chaque instance, sûr en accès concurrent.

Les protections justifiées, suggestions de style et faux positifs confirmés sont conservés. Les diagnostics du code généré ne sont pas des défauts du produit. Aucune requête de sécurité n'a été désactivée pour les masquer.

## Mise à jour

Extraire l'archive complète dans un nouveau dossier. Les profils et paramètres utilisateur restent dans leur emplacement habituel. Si l'historique est corrompu, conserver une copie pour récupération avant de l'effacer explicitement dans les paramètres. Résoudre les erreurs de stockage avant de relancer un lot avec reprise.
