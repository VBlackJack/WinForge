This is the first release to ship a checksum. WinForge enforces a publisher signature or a SHA256 on every installer it downloads; it now holds its own artifact to the same standard, and CI verifies the digest before publishing.

## Security

**Plugin sandbox escape.** The AST validator used a denylist, which cannot bound the reachable .NET surface. Measured against the real validator, `[System.Diagnostics.Process]::Start`, `[System.IO.File]::WriteAllText`/`Delete`, `[Microsoft.Win32.Registry]::SetValue`, `[System.Activator]::CreateInstance` and `[System.AppDomain]` reflection all passed. It is now an allowlist of value and container types.

The ConstrainedLanguage fallback enforced nothing either: the handler was compiled by `[scriptblock]::Create` *before* the language mode was assigned, and a scriptblock carries the mode it was compiled under - handlers reported `LanguageMode=FullLanguage` and .NET static calls succeeded. Handlers now compile inside a runspace whose `InitialSessionState` declares ConstrainedLanguage, which also blocks the usual escape.

A content fingerprint is re-checked immediately before `Import-Module`, closing a time-of-check/time-of-use window on an import that runs at the host's privilege level. `trustedPublishers` is enforced instead of being decorative configuration.

**Command detection is gated by two allowlists.** The executable list alone was never a boundary: it has to permit interpreters (`python`, `node`, `pwsh`, `ruby`, `perl`, `php`) because that is what several catalog entries probe, and an interpreter takes code as an argument. Filtering shell metacharacters does not help - `pwsh -Command Start-Process calc` contains none and ran. Detection only ever needs to ask a program for its version, so arguments are allowlisted too, configured in `Config/detection-allowlist.json` and loaded fail-closed. All three execution paths enforce both lists; one of them, the post-update verification, previously had no argument guard at all.

**REST API.** Request bodies are read under a hard cap rather than trusting the declared `Content-Length` - a chunked request reports `-1`, which passed the old check and allowed an unbounded read. Per-API-key rate limiting was implemented, exported and unit-tested but never called, so only IP-based limiting ran, and on a localhost listener every caller shares one bucket. Endpoint handlers are now validated against the same type allowlist as plugin code.

## Quality gates

The PSScriptAnalyzer configuration combined an `IncludeRules` allowlist with an `ExcludeRules` list that cancelled 21 of the rules it had just enabled: the default rule set reported 750 findings, the repo settings reported 0. The full rule set now runs, the 57 resulting errors are fixed, and each remaining exclusion carries a specific justification.

Twelve of the sixteen shipped JSON schemas had no runtime consumer, so a misspelled configuration key was silently ignored - all are enforced now. Application settings are validated on load instead of carrying decorative annotations. Coverage floors are ratcheted to just below measured coverage (.NET 38%, Pester 48%).

## Fixes worth calling out

- Files containing non-ASCII now carry a UTF-8 BOM. Windows PowerShell 5.1 read them as ANSI, so their output was garbled - and 5.1 is a real execution path.
- Nine controls that cannot derive an automation name from their content now declare a localized one.
- `Test-ObjectAgainstSchema` rejected every JSON `null`, failing validation with a misleading binding error and leaving its own null-handling branch unreachable.
- `LoadSettingsAsync` handed concurrent first-callers different settings instances, so a change made through one was invisible to the other.
- The GUI installation timeout was hardcoded while the authoritative value lived in configuration, so raising it there left the GUI killing installs early.

## Internal

`ApplicationManagementServiceImpl` is decomposed from 1635 to 1165 lines across `PackageMatcher`, `DeploymentLog`, `UpdateSourcePolicy` and `VendorCommandRunner`. A dead process wrapper carrying a latent deadlock was removed.
