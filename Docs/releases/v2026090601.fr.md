# WinForge v2026090601

[English](https://github.com/VBlackJack/WinForge/releases/tag/v2026090601)

Cette version corrige l’isolation des plugins, la perte de données des profils, les délais des processus et l’exécution des déploiements par API.

## Corrections

- Les plugins isolés ne sont plus chargés dans la session PowerShell principale. Leur chargement et leurs hooks utilisent la même copie validée dans un processus contraint.
- La sauvegarde d’un profil et la mise à jour de sa sélection conservent SystemConfig et les champs personnalisés non modifiés. Les fichiers sont remplacés atomiquement.
- Les délais d’installation, de détection, de recherche de paquets et de requête de version restent effectifs quand les sorties des processus sont ouvertes.
- L’API valide les requêtes et lance un vrai processus de déploiement. Les demandes simultanées sont refusées et l’état expose la réussite ou l’échec.
- Les archives incluent les schémas JSON requis. Leur absence provoque un échec de validation.

## Compilation et documentation

Pester est fixé à 5.7.1. ThemeForge utilise une révision exacte commune à la CI et au script local. La validation du framework en CI ne dépend plus d’ICMP. Les paquets contrôlent leurs entrées requises avant de produire la somme SHA-256.

Les README, documents, journaux des modifications et notes de version sont en anglais par défaut, avec des versions françaises séparées.

## Mise à jour

Extrayez l’archive complète dans un nouveau dossier. Conservez vos profils et paramètres utilisateur. Le paquet complet est nécessaire pour récupérer les schémas ; remplacer uniquement l’exécutable ne suffit pas.

Les clients API doivent interroger GET /api/status après un POST /api/deploy accepté. L’acceptation indique le démarrage, pas la fin du déploiement. La progression vaut actuellement 0 pendant l’exécution et 100 à la réussite.

## Vérifier le téléchargement

```powershell
$expected = ((Get-Content .\WinForge_v2026090601.zip.sha256 -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash .\WinForge_v2026090601.zip -Algorithm SHA256).Hash
if ($expected -ne $actual) { throw 'Archive checksum mismatch.' }
```
